# ASCII Bar Chart Example

This example demonstrates the usage of the ASCII Bar Chart component with static data. It shows how to:

1. Create a bar chart with different orientations
2. Customize the chart appearance
3. Update the chart dynamically

## Features

- Horizontal and vertical bar chart orientations
- Multiple character options for bars
- Adjustable chart width
- Value labels
- Axis display
- Dynamic updates

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

## Usage

Once the development server is running, you can:

1. Switch between horizontal and vertical orientations
2. Change the bar character
3. Adjust the chart width
4. Refresh the chart
